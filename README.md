# Espeons-Etch-a-Sketch
This is another fun task for the Odin Project. 
In it's simplest form, this site creates a square grid of tiles that you can paint using your mouse. 

I've tweaked the base recipe a bit, making the drawing area flexible depending on your viewing window and adding an eraser feature to clean up any mistakes.

I'm planning to add progressive darkening of tiles, color selection and the ability to tweak the canvas size from inside the page.
