# Espeons-Etch-a-Sketch
This is another fun task for the Odin Project. 
In it's simplest form, this site creates a square grid of tiles that you can paint using your mouse. There are three painting tools available:
-Pen, that instantly darkens the pixel.
-Pencil, that progressively darkens the pixel.
-Eraser, that clears the pixel.

For each of these tools the user can select one of four colors to paint with from another menu. They can also resize the painting area to one of four different grid sizes:
-8x8
-16x16
-32x32
-64x64

I'm planning on revisiting this project for code clean-up and to expand on it's features but for now I'm pretty happy with where it's at.

Enjoy!!
